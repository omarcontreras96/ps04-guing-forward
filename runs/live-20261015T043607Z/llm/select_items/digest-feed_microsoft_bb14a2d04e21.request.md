Windows is the most secure platform for agents
https://www.youtube.com/watch?v=MzhMPCeFc5w Agents don’t work like traditional apps. They can run around the clock, use tools, write code, access files, and act across systems, often without someone watching every step. That requires a new security model built for how agents actually operate. On Windows, that model comes together through containment, identity, and manageability. Containment controls what an agent can access. Identity makes clear which agent acted, so IT can distinguish agent activity from the person using the device. And manageability connects that activity into tools like Agent 365 and Intune, so organizations can set policy, monitor risk, and govern agents across the organization1. Together, these primitives allow organizations to secure, observe, and govern agents with confidence.
Expanding the ecosystem of agents on Microsoft Execution Containers, now generally available
Traditional sandbox solutions weren’t designed for agents, where containment needs can change with every prompt and tool call. We built Microsoft Execution Containers (MXC) to meet that need. Today, Microsoft Execution Containers (MXC), becomes generally available on Windows 11, enabling organizations to define which files and networks agents can access, with those policies enforced at runtime. For individuals using AI on their personal PC2, these safeguards are part of the agent experience itself, giving users a more secure way to work with these tools. While MXC works across operating systems, its deep integration with Windows gives organizations more control of their data and a broader range of containment options, from process and session isolation to WSLc, virtual machines, and Windows 365 for Agents. Leading agents already support MXC, including Codex from OpenAI, GitHub Copilot, OpenClaw, Replit, LM Studio, OpenShell from NVIDIA, and Unsloth AI. Many others will be releasing support for MXC: Anthropic Claude Code, Box, Egnyte, Heidi Health, Hermes Agent by Nous Research, Manus, Perplexity, Raycast, and Simular amongst others. We’re also excited to share that Muse for Windows, a personal AI agent from Meta, is coming soon as a native app on Windows with MXC integration, bringing another leading AI experience to Windows and providing more choice in the agents people can use on their Windows PC. To learn more about how developers can integrate their agents with MXC, visit: Microsoft Execution Containers: Policy-driven containment for AI agents.
Bringing hybrid intelligence to Windows
As AI models grow in size and capability, customers’ needs are outpacing what their cloud budgets can support. They want to make every AI token count without giving up frontier capabilities. Hybrid intelligence brings local and cloud AI together, helping customers stretch their budgets while preserving access to the intelligence they need. To bring this to life requires powerful local models, intelligent orchestration, a performant runtime, and capable silicon, all working together to create a meaningful experience.
Frontier coding intelligence, running locally on your PC
At Build, we introduced MAI Code 1.1 Flash, a 137 billion total and 6.8 billion active parameters, designed for real-world coding workloads. Today, we’re bringing that intelligence to your device, using 3-bit precision to reduce the model size by nearly 80% while preserving coding quality and supporting a 256K context window locally. In addition to MAI Code 1.1 Flash, we are bringing other powerful models like an upcoming Nemotron model from NVIDIA – with over 70 billion parameter and quantized in 2-bit to use just over 20GB of memory and DeepSeek V4 Flash, a 284B parameter model, and others for optimal speed and intelligence running locally on RTX Spark. With optimization and tuning, these models bring what was frontier-class capabilities to local PCs while preserving accuracy and performance — using less memory and fewer system resources. The goal is to keep AI responsive while leaving room for everything else you do on your PC.

Supercharging Copilot on Windows with hybrid intelligence
Recently, we introduced the new Copilot built around three experiences: Home, Code, and Autopilot. Today, we’re announcing that on Copilot+ PCs, Copilot will get supercharged with Windows hybrid intelligence, providing three key local capabilities.
- Local context. With your permission, Copilot can understand relevant content on your PC, including files and recent activity, bringing local context into the flow of work.
- Local actions. Copilot can take action on your behalf across Windows, helping complete tasks like organizing files, assessing device diagnostics, troubleshooting issues, coding, and carrying out workflows directly on your device.
- Local models. Copilot can tap into AI models running on your PC, using local compute for the right tasks while combining it with cloud intelligence when needed.
Across Home, Code, and Autopilot, hybrid intelligence makes Copilot more useful on Windows. In Home, Copilot can use local context from your PC to pull in the files you’ve been working on and help turn them into collaboration-ready artifacts. And hybrid intelligence will make Autopilot, a persistent, proactive and personal agent, even better. Hybrid intelligence brings local context, local models and PC actions into the agent flow, enabling more grounded personal agent experiences that can continue working on your behalf, even while you focus on other things.
